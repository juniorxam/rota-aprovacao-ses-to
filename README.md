# Rota da Aprovação — SES-TO

Plataforma estática de estudos para o cargo de Gestor em Saúde no concurso SES-TO.

## Como executar

Abra `index.html` no navegador. O site não precisa de backend; o progresso fica salvo localmente no navegador por meio de `localStorage`.

## Conteúdo

- Plano de revisão até a prova
- Resumos de temas relevantes
- Questões autorais com explicações
- Simulado
- Links para legislação e fontes oficiais

As questões são autorais para estudo e não representam questões oficiais da banca. Confira sempre o edital e as fontes oficiais para atualizações.
